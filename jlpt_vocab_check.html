💡 このページの使い方

「見て分かる気がする」と「自分で思い出せる」は別物です。このページでは、 答えを隠して思い出せるかを、日を空けて何度か確かめてから「習得」とします。

語の流れ

  • 未学習（最初の画面）：覚えたと思ったら ✓、覚えにくければ ★
  • ✓ → 確認中：3日後 → 10日後 → 30日後に「📝 今日の確認」に出題。3回とも「覚えてた」なら 🎓 習得
  • 確認で「あいまい」→ 翌日もう一度。「忘れた」→ 自動で ★難記 へ
  • ★難記：1日→2日→4日→7日→15日→30日→60日の間隔で復習。★を外すと未学習に戻る
  • 🎓 習得の一覧で ✓ を押すと未学習に戻し、★ を押すと難記に移せます

確認・復習のやり方

  • 単語だけが表示されます。読みと意味を頭の中で思い出してからカードをタップ
  • 答え（読み・アクセント・意味・例文）を見て、正直に 覚えてた / あいまい / 忘れた
  • 迷ったら「あいまい」。甘く判定すると習得の意味がなくなります

📦 学習データの書き出し / 読み込み

★難記・確認中・習得の状態です。コピーしてチャットに貼るか、ファイルに保存してください。別端末で「読み込み」すると統合されます（旧ページのデータとは別管理）。
読み込み：上の欄に JSON を貼るか、ファイルを選んで「読み込み」。既存データは消さず、まだ状態のない語だけ追加します。
